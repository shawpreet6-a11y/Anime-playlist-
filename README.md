# Meri Anime List

Hindi mein anime series aur movies ki list banane ke liye ek chhoti, responsive web app.

## Chalana

`index.html` ko browser mein kholiye, ya GitHub Pages par repository publish karke site kholiye. Is repository ka home page isi file se load hota hai.

## Features

- Series, movies aur apne sections ke liye alag lists
- Anime jodna, khojna, order badalna aur hatana
- Browser ke local storage mein automatic save
- Purane `animeListV1` / `animeListV2` format se basic migration

## Zaroori baat

List sirf isi browser/device ke local storage mein save hoti hai; yeh cloud sync ya backup nahi hai. Browser data clear karne par list mit sakti hai. Browser-only password ko security boundary nahi maana ja sakta, isliye app mein fake password protection nahi hai.
